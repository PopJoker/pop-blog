# Money Manager

\---

## 項目概覽

Money Manager 是一個個人財務管理應用程式，旨在幫助使用者追蹤他們的支出、預算和財務目標。

## 動機

這個專案的起點很單純...

我和女朋友想好好管理彼此的錢。

一開始用紙本記帳，但很快就發現問題一堆：不好帶、要自己算、走在路上想記還要等回家。

後來試了幾個現成工具，又覺得太複雜、流程太多，甚至有些設計真的不太行***【Daak、天天記帳真的太幼兒抱歉】***。

所以我們決定自己做一個。

**Money Manager（Meney）**就是在這樣的背景下誕生的：

一個以「夠快、夠直覺、夠簡單」為核心的記帳工具。

我們自己定義記帳邏輯、自己設計畫面，只留下真正需要的功能。

甚至因為某人曾經很沉迷刮刮樂，我們還偷偷加了一點「遊戲」進來，讓記帳不那麼無聊。

這個專案還在進化中。

如果你有任何覺得更好的想法，歡迎直接丟過來——有機會被採用，甚至會給你一點回報。



## 主要功能

* ### 實時支出追踪

  * Money Manager 允許使用者輕鬆地記錄和分類他們的日常支出，提供了明確的了解他們的花費習慣。
* ### 預算設定和目標設置

  * 使用者可以為各種類別設定預算目標，並接收提醒當他們逼近或超過限額。應用程式還啟用了使用者設定財務目標，例如儲蓄特定金額或清償債務。
* ### 視覺化和分析

  * Money Manager 提供了對使用者花費習慣的詳細視覺化，包括圖表和圖形，以幫助識別改進的領域。
* ### 整合 Supabase

  * 應用程式利用 Supabase，一個 PostgreSQL 資料庫服務，安全地儲存和管理使用者數據。
* ## 技術架構

  * 前端：以 Flutter 為基礎開發，提供原生行動體驗。
  * 後端：使用 Dart 和 Flutter 框架。
  * 資料庫：由 Supabase 提供，為安全且可擴展的數據儲存。
